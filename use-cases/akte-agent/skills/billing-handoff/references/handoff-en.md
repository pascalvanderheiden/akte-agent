# Registration, billing and closure review

Use the same dossier reference throughout. Accept direct entry with known facts.

| Review | Required evidence / pending action |
| --- | --- |
| Registration preparation | Matter, jurisdiction, actual executed copy and version; responsible notary confirms current register, attachments, deadline and authorized submission procedure. Testament: review CTR route; company: Handelsregister; property: Kadaster. These are candidate routes, not exhaustive current-law advice. |
| Execution | Attributed actual signature/execution evidence; unresolved identity, capacity, coercion or approval concerns remain visible. Generated drafts never suffice. |
| Registration report | Supplied receipt/confirmation, source and literal reference; absent receipt means pending. Never generate a reference number. |
| Invoice draft | Separate activities, dates/timekeepers when supplied, reviewed durations, rate agreement, register/other costs and evidence, explicit tax and rounding. No posting/sending. |
| Funds | Preserve separate client-funds worksheet and unresolved discrepancies/payment evidence. A zero difference is not authorization to bill or transfer. |
| Inventory | Intake, time, research, deed versions, correspondence, observations, execution/payment, registration, invoice and archive/delivery evidence; actual availability and source/version for each. |
| Correction | Preserve originals, identify affected old artifact versions, regenerate or mark stale; absent earlier artifacts remain missing, not silently reconstructed. |
| Closure | Pending human review. Save reviewed temporary files and original evidence to the approved office system; obtain real archive and delivery confirmations. Chat history is not a legal archive. |

EUR uses ROUND_HALF_UP per fee/cost line, then exact sum; half cents round away
from zero. An explicitly supplied uniform tax rate applies to each rounded
included line and is rounded to cents again before summing. Otherwise supply an
explicit tax amount/treatment, including sourced zero/exemption when appropriate.
No assumed tax. Mixed tax rates require an explicit reviewed tax amount for
this helper, not an invented average.
